Download Clix for Android

Clix ships as a direct Android APK (arm64). No app store account required — download, open, and install.

Current build: arm64 APK (~38 MB), built via EAS.

Download from Releases Build from source

The latest APK is published under the repository's Releases tab. If no release exists yet, ask the maintainer for the current build, or build locally with npx eas-cli build -p android --profile preview.

Installation

  • Download the APK on your phone (or transfer it over USB).
  • Open the file — Android may ask to allow "install from this source". Allow it.
  • Launch Clix and add a connection to your opencode server.

Availability

Clix is not yet on Google Play or F-Droid. A direct APK is the current distribution method while the app is in active development. When Play/F-Droid listings exist, they will be linked here.
