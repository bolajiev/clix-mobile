Clix

Your AI coding agent, on your phone.

Clix is an open-source Android client for the opencode AI coding agent. Stream coding sessions, watch tool calls, approve permissions, and ship code — from your phone, against your own self-hosted server.

Get the APK Setup guide GitHub
Open source · MIT · self-hosted · not on app stores yet

What it does

Streaming chat

Live SSE responses with thinking indicators, streaming cursor, and tool-call rows.

One conversation, everywhere

Phone and terminal attach to the same server and stay in sync live.

Permissions & questions

Inline allow/deny cards and one-question-at-a-time pickers.

Voice & images

Dictate prompts and attach photos — processed on device, sent to your server only.

Grouped sessions

Conversations organized by project folder, current session highlighted.

Dark-first UI

opencode palette, Claude-style navigation, borderless chat.

Project status

Clix is under active development and currently ships as a direct Android APK. It is not yet on Google Play or F-Droid — those listings do not exist for this app yet. It targets your own self-hosted opencode serve instance; Clix does not run a cloud service.

Get started

Run opencode on your machine or server, then connect from the app:

opencode serve --hostname 0.0.0.0 --port 4096

Full setup: the guide. For live terminal ↔ phone sync, attach your terminal to the same server: opencode attach http://127.0.0.1:4096.
